# tools/enrich — צריבת מקטעים בזמן-בנייה

סקריפט שמעביר את פילוח הדף (אזורים, זרימות, דיבורי-המתחיל, סדר קריאה)
מזמן-ריצה בדפדפן לזמן-בנייה: התוצאה נצרבת לתוך קובצי ה-`.html.gz`
כ-data attributes (`data-seg`, `data-i`, `data-dh`, `data-zone`,
`data-flow`, ותג `data-segv` על הדף), בתוספת עיגון מול הטקסט הדיגיטלי
המחולק לדיבורים שב-`shastext/`. התיעוד המלא — בראש
[enrich.py](enrich.py).

```bash
python3 tools/enrich/enrich.py 0              # מסכת שלמה, במקום
python3 tools/enrich/enrich.py 0 8 --out /tmp/x --dry-run
python3 tools/enrich/enrich.py --all
```

דו"ח ולידציה לכל מסכת נכתב ל-`report/<מסכת>.json` (לא נכנס ל-git):
התאמות מול הייחוס, תיקונים (מיזוג/פיצול/תיוג-מחדש), ורשומות ייחוס
שלא נמצאו.

ההעשרה מוסיפה attributes בלבד — הסרתם משחזרת את הקובץ המקורי
בייט-אחר-בייט, והסקריפט אידמפוטנטי (הרצה חוזרת מחליפה צריבה קודמת).
